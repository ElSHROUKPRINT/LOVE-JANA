# موقع جني ♥

## الرفع على GitHub Pages
1. اعمل Repository جديد (Public) على GitHub.
2. ارفع **محتويات** الفولدر ده (index.html و css و js و data و photos و music) في الريبو.
3. من Settings ← Pages ← Source: `Deploy from a branch` ← `main` ← `/ (root)` ← Save.
4. بعد دقيقة الموقع يشتغل على `https://اسم-حسابك.github.io/اسم-الريبو/`

## الأغنية والصور
- الأغنية: حطها في `music/` باسم `song.mp3` (أو غيّر الاسم من لوحة التحكم).
- صورة العين: `photos/eye.jpg`.

## لوحة التحكم (مخفية)
- افتحها بـ **٧ ضغطات سريعة** على القلب الصغير ♥ في آخر الصفحة، أو افتح الرابط وفي آخره `#admin`.
- من جواها: تعدل الرسالة والأسئلة والكوبليهات والأمنيات، تضيف روابط ريلز يوتيوب، وترفع صور وأغنية.
- كل صورة بترفعها بتتسجل تلقائياً في `data/data.js` (قسم `library`) وبتتحفظ في فولدر `photos/`.

### النشر من لوحة التحكم
- الحساب واسم الريبو بيتعرفوا لوحدهم من رابط الموقع، فمحتاج **Token واحد بس**، مرة واحدة، من ⚙ إعدادات.
- GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate. اختار الريبو ده بس، و Contents: Read and write.
- الـ Token بيتخزن في متصفحك إنت بس، مش جوه الكود.
- من غير Token: اضغط "تنزيل data.js" وبدّل بيه الملف في فولدر `data` على GitHub.

## الريلز (ستوريز زي واتساب)
- ضيف أي عدد. بتظهر دواير ملونة، لما تضغط عليها تفتح ستوري كامل بتشتغل تلقائي بدون صوت، وفيها خانة رد بتبعت على واتساب.
- حط رابط فيديو يوتيوب (Shorts أو عادي). الأفضل ترفع الفيديو 1080×1920 كـ Short وتخليه Public أو Unlisted.
- بتشتغل تلقائي بدون صوت.

## رسالة واتساب
زر "ابعتيها لي" بيفتح واتساب برقمك والرسالة مكتوبة، وهي بتضغط إرسال.
